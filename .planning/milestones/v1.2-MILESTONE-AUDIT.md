### Warnings (non-blockers)

**W-01: `BookNotFoundError` orphaned export** (`src/anna/book-service.ts:6`)
- Exported but never imported or caught. `ArticleNotFoundError` has a typed catch branch in `article-tools.ts:149`; books only catch the generic `Error` base class. Currently no functional gap (BookService never throws `BookNotFoundError`), but it is dead code and creates asymmetry.
- Affected requirements: none (no requirement mandates typed error handling)

**W-02: `getFileExtension` called statically** (`src/tools/article-tools.ts:219`)
- Called as `getFileExtension({})` — passes an empty object, bypassing all `content-disposition` and `content-type` header detection. The function always returns `".pdf"`. The dynamic header-detection capability of the shared utility is completely unused.
- Partial REF-01 concern: the function is shared as required, but its API contract is misleading.
- Affected requirements: REF-01 (partial)

**W-03: `BROWSER_USER_AGENT` not consolidated** (`src/tools/article-tools.ts:245`)
- `book-tools.ts:9` correctly imports `BROWSER_USER_AGENT` from `client.ts`. `article-tools.ts:245` has the same string hardcoded inline. Values are identical at runtime — no divergence today. But this bypasses the single-source-of-truth intention of REF-01.
- Affected requirements: REF-01 (partial)
