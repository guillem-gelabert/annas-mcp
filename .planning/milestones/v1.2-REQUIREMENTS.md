## v1.2 Requirements (Completed)

### Book Search

- [x] **BSRCH-01**: User can search Anna's Archive books by title, author, ISBN, or keywords via `book_search`
  - _Outcome: Implemented via `handleBookSearch` in `book-tools.ts`. Live test: 50 results for "The Art of Computer Programming Knuth"._
- [x] **BSRCH-02**: `book_search` results include language, format (EPUB/PDF/DJVU/MOBI/etc.), publisher, title, authors, size, MD5 hash, and page URL per result
  - _Outcome: All 8 fields verified in live output and unit tests._
- [x] **BSRCH-03**: `book_search` uses `BaseUrlManager` with offline recovery (same resilience as article tools)
  - _Outcome: Uses shared `withResolvedBaseUrl` from `tool-utils.ts`._

### Book Download

- [x] **BDWN-01**: User can resolve a book's download URL by MD5 hash via `book_download`
  - _Outcome: Live test confirmed: `3b1024674202ece2f960874a5822760d` → fastDownloadUrl._
- [x] **BDWN-02**: `book_download` returns fast_download URL only (no SciDB fallback)
  - _Outcome: `resolveBookDownload` uses `fetchFastDownload` only. SciDB fallback deferred (Go upstream doesn't implement it)._
- [x] **BDWN-03**: `book_download` accepts optional `download: true` + `downloadPath` to write the file to disk, with extension derived from the book's format field
  - _Outcome: `saveBookFile` with format-based extension (no magic bytes check — books are multi-format)._
- [x] **BDWN-04**: `book_download` uses `BaseUrlManager` with offline recovery
  - _Outcome: Uses shared `withResolvedBaseUrl` from `tool-utils.ts`._
- [x] **BDWN-05**: `book_download` file writing reuses shared security utilities (HTTPS-only URL validation, path traversal guard, atomic write, 100 MB cap, timeout)
  - _Outcome: All 5 security properties verified in `file-utils.ts` unit tests._
