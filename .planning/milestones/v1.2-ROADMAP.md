# Milestone v1.2: Book Tools

**Status:** ✅ SHIPPED 2026-05-19
**Phases:** 8–10
**Total Plans:** 5

## Overview

Added `book_search` and `book_download` MCP tools with the same quality and resilience patterns as the article tools, extracted shared security utilities to eliminate code duplication, and cleared all four deferred v1.1 tech debt items. Post-milestone quick task (260519-nr9) resolved three audit warnings before archiving.

## Phases

### Phase 8: Book Search

**Goal:** Users can search Anna's Archive for books and receive structured results with full metadata via `book_search`
**Depends on:** Nothing (extends existing client/service infrastructure)
**Requirements:** BSRCH-01, BSRCH-02, BSRCH-03
**Plans:** 2 plans

Plans:
- [x] 08-01-PLAN.md — Data and service foundation: Book type, bookSearchUrl, withResolvedBaseUrl extraction, parseBookSearchResults, BookService
- [x] 08-02-PLAN.md — Tool layer: book-tools.ts, article-tools.ts import update, server wiring, tests

**Details:**
- `Book` interface with 8 optional fields (language, format, size, title, publisher, authors, pageUrl, hash)
- `bookSearchUrl` pure function using `URLSearchParams` with `content: "book_any"`
- Generic `withResolvedBaseUrl<S,T>` extracted to `tool-utils.ts` — eliminates duplication between article and book tools
- `parseBookSearchResults` using same selectors as article parser; private helpers for language/format parsing
- `BookService.searchBooks(query)` mirroring ArticleService pattern
- `book_search` MCP tool with Zod-validated `structuredContent` alongside `content[0].text`
- 33 tests passing (3 new book-tools tests, 4 new anna.test.ts tests)

### Phase 9: Book Download

**Goal:** Users can resolve a book's download URL and optionally save the file to disk via `book_download`, using the same security guarantees as article download
**Depends on:** Phase 8
**Requirements:** REF-01, BDWN-01, BDWN-02, BDWN-03, BDWN-04, BDWN-05
**Plans:** 2 plans

Plans:
- [x] 09-01-PLAN.md — File utils extraction + BookDownloadResolution type
- [x] 09-02-PLAN.md — book_download MCP tool, security tests, service tests

**Details:**
- `src/anna/file-utils.ts` new shared module: `validateDownloadUrl`, `sanitizeFilename`, `safeJoinPath`, `getFileExtension` — REF-01 complete
- `BookDownloadResolution` interface `{ book: Book; fastDownloadUrl: string }`
- `resolveBookDownload(hash)` in BookService — calls `fetchFastDownload`, throws on empty URL
- `book_download` MCP tool: `handleBookDownload`, `saveBookFile` (30s timeout, 100MB cap, HTML check, no magic bytes, format-based extension)
- Both article and book tools now import security utilities from shared `file-utils.ts`
- 48 tests passing (5 new book_download handler tests, 2 resolveBookDownload tests, 8 file-utils security tests)

## Milestone Summary

**Post-Milestone Quick Task (260519-nr9):**
- W-01: `BookNotFoundError` now has typed catch branch in `handleBookDownload` (mirroring article pattern)
- W-02: `getFileExtension({})` call in article-tools.ts documented with explanatory comment (articles are always PDF)
- W-03: `BROWSER_USER_AGENT` imported from `client.ts` in article-tools.ts (eliminates inline duplication)

**Key Decisions:**
- `book_download` uses fast_download only — no SciDB fallback (Go upstream does not implement one for books)
- `book_download` extension derived from book's format field (format-agnostic, no PDF-only magic bytes check)
- REF-01 (file-utils extraction) shipped in Phase 9 alongside book_download (the first consumer needing shared security utils)
- Tech debt items (TD-01–TD-04) grouped in Phase 10 for clean separation from feature work
- `downloadPath` follows same optional-at-config / required-at-call pattern as `article_download`
