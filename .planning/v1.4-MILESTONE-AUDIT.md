## Post-Phase Design Change (Critical Context)

**Commit `35dd4cd`** (2026-05-28, authored by Guillem Gelabert Sunyer) replaced the Phase 17 GREEN state with a hard-error gating model:

| Aspect | Phase 17 GREEN (fd7bf2e) | Live code (35dd4cd) |
|--------|--------------------------|----------------------|
| Success response | `{ article, sources, verification: { crossrefTitle, annasTitle, confidence } }` | `{ article, sources }` — no `verification` field |
| `confidence === "low"` | Success with `confidence: "low"` in verification | `isError: true` — title mismatch error |
| `confidence === "unverified"` | Success with `confidence: "unverified"` | `isError: true` — cannot verify error |
| `verificationSchema` | Defined and in output schema | Deleted |

The commit message is explicit: *"Drop verbose flag; Crossref is now fetched unconditionally on every download. Single and batch paths both error (isError: true) on confidence 'low' or 'unverified'. Remove verificationSchema and verification output fields — success responses contain only article + sources."*

**Interpretation:** This is an intentional design upgrade, not a regression. The hard-error model provides stronger guarantees to callers than the additive model. However, the v1.4 requirements text was written for the additive model and has not been updated.

## Audit Conclusion

v1.4 DOI Verification delivered its core goal: Anna's Archive DOI resolution is now cross-validated against CrossRef on every `article_download` call. The three stale requirement texts (VER-07, VER-08, VER-09) are documentation gaps resulting from the intentional post-phase design change. No functionality is missing. No integration is broken.
